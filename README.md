# lacOs

My portfolio, dressed up as a classic Mac (Mac OS 8 "Platinum"). Built with Angular 21.

- Draggable, resizable windows with zoom, minimize and WindowShade (double-click the title bar)
- Working menu bar, right-click menus, dock and desktop icons (double-click to open)
- Apps: About, Finder, Experience, Projects (live from GitHub), Courses, Books, Blog (Medium), Safari, Terminal (with games), Notes, Quiz (with a secret)
- English and Portuguese
- Touch-friendly layout on phones

## Development

```bash
npm install
npm start       # http://localhost:4200
npm test
npm run build
```

See [CLAUDE.md](CLAUDE.md) for the code structure.
